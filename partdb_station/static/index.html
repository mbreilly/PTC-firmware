MAKING AN API TOKEN

  1. Open Part-DB and log in.
  2. Click your user name at the top right, then User settings.
  3. Under API tokens, add a token. Give it a name like "label station", access level Edit (or Admin if the supplier lookups say they aren't allowed), and no end date.
  4. Copy the token (it starts with tcp_) and paste it here.

SUPPLIER LOOKUPS

Descriptions, categories, footprints, datasheets and prices come from the info providers switched on in Part-DB under Tools → Info providers. LCSC needs no key; DigiKey and Mouser need their own API keys there. Without any, the station still fills in what the label itself says.

SCANNERS

Any USB scanner that reads 2D codes and acts as a keyboard works. DigiKey and Mouser labels use DataMatrix codes with hidden separators; if a scan comes out as one long run of text, set the scanner to send the separator (GS) as Ctrl+], or as the text <GS>.
